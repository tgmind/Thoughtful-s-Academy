# Backend API Catalog & Interface Matrix

**Platform:** Graviton Academy (Coaching Institute Management System)  
**Architecture:** Direct PostgREST 12+ Data API via `@supabase/supabase-js` + Serverless Functions  
**Base URL (PostgREST):** `https://<supabase-project-id>.supabase.co/rest/v1`  
**Base URL (Edge Functions):** `https://<supabase-project-id>.supabase.co/functions/v1`  
**Base URL (Netlify):** `/.netlify/functions` (proxied to `/api/youtube-playlist` in dev)  
**Authentication Scheme:** Bearer JWT in `Authorization` header (`Bearer <access_token>`)  

---

## 1. Executive Summary & Interface Taxonomy

The backend architecture departs from traditional monolithic Node/Express REST APIs by employing a **Backend-as-a-Service (BaaS)** model. Client applications interact directly with the database through **Supabase PostgREST**, where Row Level Security (RLS) policies serve as the primary API authorization gateway.

Backend computational interfaces are grouped into:
1. **PostgREST Table Interfaces (19 Data Entities):** CRUD operations filtered and shaped via URL query parameters (`select`, `order`, `filter`).
2. **Serverless Edge Function (`send-push`):** Webhook-triggered background push notification dispatcher running on Deno.
3. **Netlify Serverless Function (`youtube-playlist`):** Server-side HTTP proxy parsing YouTube XML/HTML feeds to bypass CORS restrictions.
4. **Supabase Realtime WebSockets:** Bidirectional WebSocket subscription channels listening to database write-ahead log (WAL) change streams.

## 3. PostgREST Query Construction Standards

Client-side requests generated by `@supabase/supabase-js` follow deterministic URL formatting:
- **Relational Joins:** Embedded foreign keys via `select=*,batches(name),profiles(full_name)`.
- **Filtering Operators:** `eq`, `neq`, `gt`, `gte`, `lt`, `lte`, `in`, `is`, `like`, `ilike`.
- **Ordering:** `order=created_at.desc`.
- **Pagination:** `range(start, end)` mapping to HTTP `Range: <start>-<end>` headers.
- **Count Headers:** `count: "exact"` producing `Preference: count=exact` and `Content-Range` response headers.
